## DESKRIPSI SINGKAT TENTANG REPOSITORY  

Respository GitHub adalah tempat penyimpanan project di GitHub yang berisi source code, file project, aset, dokumentasi, dan histori perubahan project. Repository ini difungsikan untuk melacak setiap tahapan perubahan kode (version controlling) selama proses pengembangan berlangsung, sekaligus menjadi tempat pengumpulan hasil akhir dari implementasi aplikasi yang telah dibangun.

## RANGKUMAN MATERI WORKSHOP

- **Prompt Engineering**: Prompt adalah instruksi yang diberikan kepada model AI untuk mendapatkan hasil tertentu. Agar AI memberikan jawaban yang akurat, konteks sangatlah penting. Struktur prompt yang ideal harus mencakup *Role*, *Task*, *Context*, dan *Format*. Keuntungan menggunakan teknik ini adalah dapat meningkatkan performa AI, dan meningkatkan kontrol kita terhadap hasil akhir.
- **Git & GitHub**: Git adalah sistem pengontrol versi yang diciptakan oleh Linus Torvalds pada tahun 2005 untuk melacak perubahan pada file. GitHub adalah platform online untuk menyimpan repository Git dan melakukan kolaborasi.

   Workflow Git secara umum melewati tiga tahap:
1. Working Directory (tempat bekerja)
2.  Staging Area (menyiapkan file)
3.   Repository/ `.git` directory (tempat penyimpanan akhir).

---

## POIN-POIN PENTING & PENGETAHUAN BARU
- **Pentingnya Konteks pada Prompt AI:** Penerapan kerangka kerja "Role, Task, Context, Format" terbukti sangat efektif untuk menghasilkan output AI yang lebih akurat dan spesifik.
- **Perbedaan Git dan GitHub:** Git adalah sistem pengontrol versi yang beroperasi secara lokal, sedangkan GitHub adalah platform berbasis web untuk penyimpanan dan kolaborasi repository.
- **Alur Kerja Git:** Penguasaan siklus perintah dasar Git, yaitu `git init` (memulai), `git add` (memasukkan ke staging), `git commit` (menyimpan versi), dan `git push` (mengunggah ke GitHub).
